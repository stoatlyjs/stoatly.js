# Changelog

## 0.2.0

**Fixed**
- `$onlyIf` (and the new `$stop`) now actually halt command execution.

**Added**
- Logic: `$switch`, `$not`, `$stop`, `$try`
- Context: `$channelName`, `$serverName`, `$mentionsCount`, `$isBot`
- Actions: `$startTyping`, `$stopTyping`
- Utility strings: `$length`, `$substring`, `$replace`, `$split`, `$trim`,
  `$indexOf`, `$includes`, `$capitalize`, `$padStart`, `$padEnd`,
  `$repeatText`
- Utility numbers/dates: `$round`, `$floor`, `$ceil`, `$abs`, `$timestamp`,
  `$formatDate`

## 0.1.0

Initial release.
